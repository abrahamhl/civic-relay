## 2026-11-07 19:xx UTC — code-level ingestion blockers confirmed against PR #18

Inspected `packages/senda/data/fetch_real_usgs_comcat.py` and `.github/workflows/senda-public-datasets.yml` at PR #18 head `ece979b5c5be510a5a5d413fbd261b37aaa88ddb`. No new provider acquisition or rights grant is asserted.

1. **Silent catalog truncation risk**: USGS query sets `limit=500`, and `normalize_catalog` accepts `len(features) == 500` without checking total matched count or paginating. A saturated response may be incomplete without warning. For any scientific dataset, require `metadata.count` reconciliation and/or explicit page retrieval; fail closed on unknown completeness.
2. **Nonfinite numeric risk**: `json.loads(raw)` in Python accepts nonstandard `NaN`/`Infinity` tokens by default, while coordinate and magnitude validation only checks numeric type and range. A nonfinite depth is not range-checked at all. Reject nonfinite values via `parse_constant` and `math.isfinite`, and verify depth range/uncertainty separately.
3. **Redirects are followed before rejection**: `urllib.request.urlopen` follows HTTP redirects by default; the later `response.geturl() != url` check only detects the redirect after a request has already reached its destination. For an immutable provenance gate, disable redirects before opening or enforce a strict allowlist at redirect handling.
4. **No event-publication timestamp**: the normalized object explicitly states original publication time unknown; `revision_updated_utc` is not the initial publication time. Keep `available_at_utc` unknown for retrospective real-time replay until a source-backed timestamp exists.
5. **Workflow success is not ingestion success**: both live acquisition steps use `continue-on-error: true`; an overall green job can coexist with failed downloads. Require a separate machine-readable acquisition status and evidence gate before marking a source ingested.

**Recommended independent patch**: add contract tests for 500-row saturation, `NaN`/infinite depth, redirect response, absent original publication time and partial workflow success; change only ingestion tooling on a separate research branch after review.
