# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Civic Relay, please report it privately to:

**Email:** security@civic-relay.example.com

Please include:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We aim to respond within 48 hours and will keep you updated on the remediation progress.

## Scope

This security policy applies to:
- Civic Relay core packages (@civic-relay/*)
- Web application (apps/web)
- Deployed instances (civic-relay.github.io)

## Out of Scope

- Third-party dependencies (report to their maintainers)
- Demo/test instances (clearly marked as non-production)

## Public Disclosure

We follow coordinated disclosure:
1. You report the issue privately
2. We confirm and develop a fix
3. We release a patch
4. After 90 days (or earlier if agreed), we publish a security advisory

## Bug Bounty

Currently, we do not offer a bug bounty program. This may change in the future.

## Security Best Practices

When deploying Civic Relay:
- ✅ Use HTTPS only
- ✅ Keep dependencies updated
- ✅ Enable audit logging
- ✅ Follow ENS Alto compliance (for Spanish public sector)
